Support

SimpleComic is a lightweight comic and sticker creation app designed for iPad and Apple Pencil.

Key features

  • Create Comic and Sticker projects
  • Draw with brush, eraser, and fill tools
  • Add, edit, and move text
  • Manage layers, layer order, opacity, and blend modes
  • Create comic panels with Panel Split
  • Create stickers with transparent backgrounds
  • Export artwork as PNG images
  • Use iPhone companion for auxiliary text input
  • Export and import project backup files

How to use SimpleComic

  1. Create or open a project from the project list.
  2. Choose a Comic or Sticker project.
  3. Use the drawing, eraser, fill, text, and layer tools on the drawing page.
  4. Use Panel Split to create panel layouts in Comic projects.
  5. Export the finished work as a PNG image, or export a project backup through the system share sheet.

iPhone companion

  1. Open SimpleComic and a project on the iPad.
  2. Make sure the iPhone and iPad are connected to the same local network.
  3. Open the text input page in SimpleComic on the iPhone.
  4. Allow Local Network and Bluetooth access, then accept the connection request.
  5. After connecting, use the iPhone as an auxiliary text input device for the current iPad project.

Troubleshooting

iPhone cannot connect to iPad

Make sure both devices are connected to the same Wi-Fi network and that Local Network and Bluetooth access are allowed. Open a project on the iPad before opening the text input page on the iPhone. If the problem continues, restart SimpleComic on both devices and try again.

Photo access

Photo access is used only when you explicitly choose Save to Photos. SimpleComic does not read your existing photo library.

Project storage

Projects and thumbnails are stored locally on the device and are not automatically uploaded to a server. Exported backup files are managed by the location you choose when sharing them.

支持

SimpleComic 简单漫画是一款面向 iPad 和 Apple Pencil 的轻量漫画与贴纸创作工具。

主要功能

  • 创建 Comic 和 Sticker 项目
  • 使用画笔、橡皮擦和填充工具绘画
  • 添加、编辑和移动文字
  • 管理图层、图层顺序、透明度和混合模式
  • 使用 Panel Split 创建漫画分格
  • 创建透明背景贴纸
  • 导出 PNG 图片
  • 使用 iPhone companion 辅助输入文字
  • 导出和导入项目备份文件

基本使用方法

  1. 在作品列表页新建或打开一个项目。
  2. 选择 Comic 或 Sticker 项目类型。
  3. 在绘制页使用画笔、橡皮擦、填充、文字和图层工具。
  4. Comic 项目可以使用 Panel Split 创建分格布局。
  5. 完成作品后，可以导出 PNG，或通过系统分享功能导出项目备份。

iPhone companion 使用方法

  1. 在 iPad 上打开 SimpleComic，并打开一个项目。
  2. 确认 iPhone 和 iPad 连接到同一个局域网。
  3. 在 iPhone 上打开 SimpleComic 的文字输入页面。
  4. 允许本地网络和 Bluetooth 权限，并接受连接请求。
  5. 连接成功后，可以使用 iPhone 辅助输入文字到 iPad 当前项目。

常见问题

为什么 iPhone 无法连接 iPad？

请确认两台设备连接到同一个 Wi-Fi 网络，并允许 SimpleComic 使用本地网络和 Bluetooth。请先在 iPad 上打开项目，再在 iPhone 上打开文字输入页面。如果仍然无法连接，请关闭并重新打开两台设备上的 SimpleComic 后重试。

为什么需要照片权限？

照片权限仅用于在用户主动选择“保存到照片”时写入导出的 PNG。SimpleComic 不读取用户已有的照片。

项目文件保存在哪里？

项目和缩略图默认保存在当前设备上的 SimpleComic 本地存储中，不会自动上传到服务器。导出的备份文件由用户选择的保存位置负责管理。
